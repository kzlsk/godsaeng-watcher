## 변경 내용

### `src/shared/ui/Button.tsx`

- `kakao` variant — 카카오 공식 버튼 스펙
  - 배경: 기존 `bg-yellow` 토큰 유지 (`--color-yellow: #fee500` = 카카오 브랜드 컬러.
    globals.css에 다크모드에서도 변경하지 않는다고 명시돼 있어 그대로 사용)
  - 라벨: `text-ink` → `text-black/85`. ink는 다크모드에서 #e0e0e0으로 뒤집히는데
    버튼 배경은 항상 노란색이라 라벨이 거의 안 보이게 됨. 공식 스펙도 #000000 85%임
  - 테두리: `border-line-strong` → `border-transparent` (공식 버튼은 테두리 없음)
  - 모서리: `rounded-xl` 추가 (이미지 기준 ~12px)
- `google` variant — 구글 공식 버튼(라이트 테마) 스펙
  - 배경 `bg-white`, 라벨 `text-[#1f1f1f]`, 테두리색 `#747775`, `rounded-xl`
  - hover: 공식 상태 레이어가 #303030 8% 오버레이라 흰 배경 위 결과값인 `#eeeeee`로 대체

### `src/features/login-with-oauth/ui/OAuthButtons.tsx`

- 카카오 말풍선 심볼, 구글 "G" 로고를 각각 인라인 SVG(`KakaoSymbol`, `GoogleSymbol`)로 추가.
  둘 다 브랜드 색 고정(카카오 #000000 / 구글 4색 원본)이라 테마 토큰을 쓰지 않음
- 라벨: `카카오로 계속하기` → `Login with Kakao`, `Google로 계속하기` → `Sign in with Google`
  (각각 받은 이미지/마크업 그대로)

## 검토한 대안과 채택 이유

- **아이콘을 `src/shared/ui/`로 분리**: 사용처가 로그인 버튼 1곳뿐이라 feature 슬라이스 안에 둠.
  다른 곳에서도 쓰이면 그때 shared로 올리면 됨
- **`rounded-xl`을 variant가 아니라 호출부 className에 두기**: 공식 버튼은 "색 + 모양"이 한 세트라
  variant에 묶는 게 맞다고 판단. `kakao`/`google` variant 모두 이 버튼 외 사용처 없음
- **구글 테두리를 공식 1px로 맞추기**: 채택하지 않음. `cn()`이 tailwind-merge가 아니라 단순 join이라
  공통 클래스 `border-2`와 variant의 `border`가 같은 속성으로 충돌하고, 승자가 Tailwind의
  유틸리티 정렬 순서에 달려 불안정함. 또 1px이 되면 카카오 버튼과 전체 높이가 2px 어긋남.
  앱 전체가 2px 테두리 디자인이기도 해서 색만 공식값(#747775)으로 맞추고 두께는 2px 유지
- **아이콘 크기**: 카카오 공식 18px / 구글 공식 20px(40px 버튼 기준)이지만 둘 다 18px로 통일.
  이 앱 버튼은 lg 사이즈라 높이가 ~58px여서 공식 비율을 그대로 쓰는 게 의미가 없고,
  나란히 쌓이는 두 버튼의 심볼 크기가 맞는 쪽이 보기에 낫다고 판단
- **다크모드에서 구글 공식 다크 테마(배경 #131314 등) 적용**: 하지 않음. globals.css에
  `@custom-variant dark`가 없어 Tailwind `dark:`가 `html[data-theme="dark"]`를 따라가지 않고,
  이를 추가하는 건 이 티켓 스코프 밖. 카카오 버튼과 동일하게 브랜드 색 고정 방식으로 통일함
