  진회색, 텍스트는 #e0e0e0 수준, 강조색(쓴소리 배너 빨강, 스트릭 초록 등)은 채도 낮춤. 요소의 의미는 유지.
- DoD: 다크 배경이 순검정 아닌 진회색 / 텍스트 순백 아님 / 강조색이 과하게 튀지 않음 / 라이트모드 영향 없음

- 색상 토큰은 `shared/ui/**`에 없고 `src/app/globals.css`에만 정의되어 있음 (`shared/ui`에는 토큰을 쓰는 컴포넌트만 있음).
- 사용자에게 확인 → "globals.css로 scope 확장" 승인받아 진행. 컴포넌트 파일은 수정하지 않음.

## 점검 결과 (수정 전 다크 토큰의 문제)

1. **텍스트가 거의 순백**: `ink #fffdf7` (패널 대비 17:1). ink는 텍스트뿐 아니라 모든 2px 테두리, 솔리드 버튼 배경,
   브루탈 그림자에도 쓰여서 화면 전체에 흰 선/흰 블록이 생김 → 눈부심의 주원인.
2. **브루탈 그림자가 흰 판이 됨**: `--shadow-brut`가 `var(--color-ink)`라 다크에서 대시보드/로그인 카드 오른쪽 아래에
   8px 폭의 거의 흰 띠가 생김.
3. **층위 역전(라이트 값 단순 반전 패턴)**: 페이지 배경 `surface #221f16`이 패널 `paper #17150f`보다 밝음.
   다크모드에서는 위에 올라온 요소가 더 밝아야 자연스러운데 반대로 되어 있었음. 또 전체가 누런 갈색 톤.
4. **강조색 미조정**: red/green 계열은 다크 오버라이드가 없어 라이트 값을 그대로 씀.
   - `red #c53e19`는 채도 0.77의 형광 주황빨강 → 쓴소리 배너 전체가 강하게 튐.
   - 배너 글자는 `text-paper-3`인데 다크에서 paper-3가 거의 검정이라 빨강 위 검정 글씨, 대비 3.54:1 (AA 미달).
   - `red-shadow`(중요 뱃지·"삭제할까요?" 등 텍스트)는 어두운 배경 위 대비 2.78:1로 읽기 어려움.
   - `green`(완료율 수치, 완료 뱃지)도 3.43:1, `green-deep`(스트릭 점) 2.78:1로 어두운 배경에 묻힘.

  중간 회색(#3a3a3a~#4a4a4a)으로** 낮춰 halation 제거. 라이트모드 영향 없음.
- 배경/텍스트/강조색은 직전 작업(다크모드 색상 토큰 수정)에서 이미 반영되어 있어, 이번 실작업은 테두리.

## scope 조정 (사용자 승인)

- 테두리는 모두 `border-ink`(= 본문 글자색 토큰)를 사용 → 토큰 값만 바꾸면 글자도 같이 회색이 되어 불가.
- `border-ink` 사용처가 17개 파일이고 그중 `shared/ui`는 8개뿐이라 scope 안에서만 고치면 DoD 미충족.
- 사용자에게 선택지 제시 → **"토큰 분리 + 전체 교체"** 승인. `src/app/globals.css` + `border-ink` 사용 파일 전체로 확장.

## 설계

- 테두리 전용 토큰 2개 신설 (`:root`에서는 둘 다 `var(--color-ink)` → 라이트모드 픽셀 단위로 동일)
  - `--color-line` (다크 `#444444`): 카드 틀, 구분선, 스켈레톤, 비조작 칩/뱃지, 로고. 패널 대비 1.79:1.
  - `--color-line-strong` (다크 `#6e6e6e`): 입력창, 체크박스, 테두리형 버튼, 테마 토글, 휠피커.
    WCAG 1.4.11(비텍스트 대비 3:1) 충족을 위해 요청 범위보다 밝게 둠. 패널 대비 3.41:1.
- `border-ink` 유지 3곳: `bg-ink`로 꽉 찬 요소(Button solid, Badge solid, 헤더 로그아웃 버튼).
  테두리가 배경과 같은 색이라 halation 원인이 아니고, 회색으로 바꾸면 밝은 블록에 어두운 링이 생김.
