# 015 — UI 버그 수정 (닉네임 표시 / 미션 삭제 버튼 / 미션 추가 버튼 스타일)

## 받은 티켓 스펙 요약

- scope: `widgets/dashboard-header/**`, `entities/mission/ui/**`,
  `features/delete-mission/**`(신규), `widgets/mission-board/**`
  (tickets/015.md 파일은 저장소에 없어 사용자가 채팅으로 직접 준 스펙을 티켓 스펙으로 취급함.
  이 리포의 위젯은 폴더가 아니라 단일 파일이라 `widgets/dashboard-header/**` →
  `src/widgets/DashboardHeader.tsx`, `widgets/mission-board/**` → `src/widgets/MissionBoard.tsx`로 해석함)
- 요구사항
  1. 헤더 닉네임이 3글자 이상이어도 앞 2글자만 보이는 버그 수정
  2. 미션 삭제 버튼(휴지통 아이콘) + 확인 단계 추가, `useDeleteMission` 훅 신규
     (DELETE `/api/missions/:id`는 004에서 구현됨)
  3. 미션 추가 버튼을 키우고 좌우 여백 확보, 목록과 버튼 사이 구분선 추가

## 원인 분석 (닉네임)

- `DashboardHeader`가 `entities/user/ui/UserAvatar`에 닉네임을 넘기는데, `UserAvatar`는
  고정 크기(`size-8.5`) 이니셜 아바타라 `nickname.slice(0, 2)`로 앞 2글자만 렌더링함.
- `entities/user/**`는 scope 밖이라 `UserAvatar`는 건드리지 않고, scope 안인 `DashboardHeader`에서
  아바타 대신 전체 닉네임을 그대로 표시하는 칩(`whitespace-nowrap`, 잘림 없음)으로 교체함.
  기존과 동일하게 모바일(sm 미만)에서는 숨김 유지.
- 참고: 이 변경으로 `UserAvatar`는 현재 어디서도 import되지 않음(삭제는 scope 밖이라 보류).

  features를 참조하지 않도록 삭제 동작은 콜백으로 주입받음. `useState` 사용으로 `"use client"` 추가.

- `src/widgets/DashboardHeader.tsx` — `UserAvatar`(2글자 이니셜) 대신 전체 닉네임 칩 표시.

# 015 추가 작업 — UserAvatar 정리 + 로그아웃 기능

## 받은 스펙 요약

- scope: `widgets/dashboard-header/**`(= `src/widgets/DashboardHeader.tsx`), `entities/user/**`,
  `features/logout/**`(신규)
- 요구사항
  1. 더 이상 쓰이지 않는 `entities/user/ui/UserAvatar.tsx` 삭제
  2. `features/logout/model/useLogout.ts`: Supabase `auth.signOut()` 호출 훅
  3. 로그아웃 성공 시 `/login`으로 이동, 이동 전에 `queryClient.clear()`로 TanStack Query 캐시 전부 비우기
  4. DashboardHeader 닉네임 칩 옆에 로그아웃 버튼 추가

## 변경한 파일 목록

### 신규

- `src/features/logout/model/performLogout.ts` — signOut → clearCache → redirectToLogin 순서를 강제하는
  순수 함수(의존성 주입). signOut이 `{ error }`를 돌려주면 에러를 던지고 캐시 삭제/이동을 하지 않음
  (세션이 아직 살아 있는데 화면만 로그인으로 가는 상태 방지).
- `src/features/logout/model/performLogout.test.ts` — 성공 시 호출 순서, 실패 시 캐시 삭제/이동 안 함 검증 (2 tests).
- `src/features/logout/model/useLogout.ts` — `useMutation` 래퍼. 브라우저 Supabase 클라이언트의
  `auth.signOut()`, `queryClient.clear()`, `window.location.replace("/login")`을 주입.
  - `router.replace` 대신 전체 페이지 이동을 쓴 이유: Next 클라이언트 라우터 캐시, `useUser`의 로컬 상태,
    `Providers`의 QueryClient 인스턴스 등 메모리에 남은 이전 유저 흔적을 확실히 초기화하기 위해서.
    `replace`라 뒤로가기로 대시보드에 돌아가지도 않음.

### 수정

- `src/widgets/DashboardHeader.tsx` — 닉네임 칩 오른쪽에 로그아웃 버튼 추가(모바일 포함 항상 표시,
  진행 중에는 "로그아웃 중…" + 비활성화, 실패 시 alert). 훅 사용으로 `"use client"` 추가.
  UserAvatar 관련 주석 정리.

### 삭제

- `src/entities/user/ui/UserAvatar.tsx` (참조 0건 확인 후 삭제, 커밋 규칙에 맞춰 unstaged 상태로 둠)
